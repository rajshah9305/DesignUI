# UI Design Agent

An AI-powered UI design assistant that generates sophisticated user interfaces using multiple language models.

## Features

- Support for multiple AI models (Mistral, Mixtral, Llama3)
- Real-time code generation
- Syntax highlighting
- Responsive design
- Dark mode interface

## Tech Stack

- **Backend**: Node.js, Express
- **Frontend**: React, Vite, TailwindCSS
- **AI Models**: OpenRouter, Together AI, Groq

## Prerequisites

- Node.js >= 16.0.0
- npm >= 8.0.0
